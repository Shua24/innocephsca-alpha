# Innocephsca Alpha

**A personal fork of [Iosevka](https://github.com/be5invis/Iosevka).** This repository is *not* upstream Iosevka: it is a fork based on Iosevka **34.9.0** that exists to build one custom family, **Innocephsca Alpha**, from a single build plan.

Looking for Iosevka itself — the full family, official releases, the Customizer? Go to [be5invis/Iosevka](https://github.com/be5invis/Iosevka).

## What this fork changes

The complete diff against upstream 34.9.0 is three files; every glyph design, metric, OpenType feature, build tool and document under them is upstream code, untouched:

* `build-plans.toml` — upstream's 73 build plans are replaced by a single plan, `[buildPlans.InnocephscaAlpha]`, described below.
* `private-build-plans.sample.toml` — deleted.
* `package-lock.json` — regenerated by a local `npm install` (metadata only; no dependency or version changes).

### The family

8 styles, all `sans` serifs and `normal` spacing:

| | |
| --- | --- |
| Weights | Regular (400), Bold (700) |
| Widths | Normal, Condensed |
| Slopes | Upright, Italic (9.4°) |

File names follow `InnocephscaAlpha-<Width><Weight><Slope>.ttf`, for example `InnocephscaAlpha-CondensedBoldItalic.ttf`. The Condensed styles report a separate family name, `Innocephsca Alpha Condensed`, in the font metadata.

## Building

Requirements, as per upstream's [build instructions](doc/custom-build.md): Node.js 18+ and [ttfautohint](https://freetype.org/ttfautohint/) (used for the hinted builds). Make sure both are on `PATH`.

```bash
npm install
npm run build -- contents::InnocephscaAlpha
```

The result lands in `dist/InnocephscaAlpha/`: hinted and unhinted TTFs and WOFF2 files (8 styles each, in `TTF/`, `TTF-Unhinted/`, `WOFF2/` and `WOFF2-Unhinted/`) plus the webfont CSS files.

To build only part of it, use another target with the same plan name: `ttf::`, `ttf-unhinted::`, `webfont::`, `webfont-unhinted::`, `woff2::` or `woff2-unhinted::` instead of `contents::`. Add `--jCmd=<number>` to cap the number of concurrent jobs — each one can peak above 1 GB of RAM, and the default is one job per CPU thread. All build-plan options are documented in [doc/custom-build.md](doc/custom-build.md).

## Installing

This fork publishes no releases; install from your own build. On Linux:

```bash
install -d ~/.local/share/fonts/InnocephscaAlpha
install -m644 dist/InnocephscaAlpha/TTF/*.ttf ~/.local/share/fonts/InnocephscaAlpha/
fc-cache -f
```

Use `sudo` and change the `~/.local/share/fonts/` directory into `/usr/share` if your linux distro follows the FHS (Filesystem Hierarchy Standard) i.e. uses the typical /usr/share/ directory for fonts

On Windows, drag the `.ttf` files into the font settings; on macOS, open them with Font Book.

## Syncing with upstream

This repository has no `upstream` remote configured; add it once:

```bash
git remote add upstream https://github.com/be5invis/Iosevka.git
git fetch upstream
```

The fork's own state is a single commit touching three files, so expect a merge from upstream to conflict in `build-plans.toml` first.
